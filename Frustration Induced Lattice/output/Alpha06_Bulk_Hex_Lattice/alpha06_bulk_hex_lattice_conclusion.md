# alpha=0.6 pi 体内六角 Lattice 与谱尺度检验

## 结论

`Dispersion.py` 在 alpha=0.6 pi 处是有限的：消元分母为
`-39.46884543`。最大实部给出

- `k* = 5.091025340`；
- `max Re sigma = 0.374192497`；
- `2pi/k* = 1.234168932`。

但六角/三角点阵中，`2pi/k*` 是第一族晶格面的间距，不是团簇中心最近邻
晶格常数。若第一圈 Bragg 峰满足 `|G_1|=k*`，则

`a_hex = 4pi/(sqrt(3) k*) = 1.425095530`。

三个 50000 步初值的旋转中心第一壳层距离为 `1.371834776`，seed 均值范围
`[1.351282594, 1.410195716]`。于是：

- 把 `2pi/k*` 直接当最近邻距离：偏差 `+11.15%`；
- 使用六角倒格矢关系：偏差 `-3.74%`；
- 等价地，实测晶格面距 `sqrt(3)a/2=1.188043765` 与 `2pi/k*`
  的偏差为 `-3.74%`。

旋转中心径向结构因子的第一 Bragg 峰平均为 `k_B=5.290000`，相对线性
`k*` 偏差 `+3.91%`。因此线性谱对体内六角晶格给出了较好的近似
尺度选择，但不是精确等式；残差包含非线性饱和、圆盘边界应变和有限晶格缺陷。

## 测量定义

每个粒子的瞬时旋转中心按

`c_i = x_i + (v/dot(theta_i)) (-sin(theta_i), cos(theta_i))`

计算；在旋转中心空间用 DBSCAN 识别涡旋，排除距圆壁小于
`0.50 d0` 的中心。晶格常数取第一壳层无向键距离，
而不是每个中心的最短单一距离。分析最后 50 时间单位，每个
初值抽取约 0.5 时间单位一帧。

## 稳健性

DBSCAN 半径 0.10--0.152 d0、体区壁面排除 0.40--0.70 d0 时，测量范围为
`[1.319793, 1.413817]`。逐 seed 时间统计、六角序参量、
配位数和结构因子峰见 CSV。
