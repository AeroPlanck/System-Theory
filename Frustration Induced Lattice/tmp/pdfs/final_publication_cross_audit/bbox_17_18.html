For every ﬁle, the code checks the required datasets, column numbers, particle count, and frame alignment. Finite values are checked in the loaded analysis window, not over each ﬁle’s entire history; the two phase-lag endpoints return without loading that window. It then calculates the two measures for the 36 rows with 0 < α < π, including the four exact α = π/2 rows. No trajectory is restarted or continued. Every ﬁle uses random seed 9; therefore the reported values are for one realization of each parameter set. Consecutive time blocks are correlated, so no binomial error bars are assigned. For α > π/2, the neighbor sum in Eq. (6.9) is evaluated with a vectorized particle-pair algorithm. We compared it with the original simulation loop on one saved frame from each geometry.
